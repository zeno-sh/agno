# 计算器

从技能目录运行 `python3 scripts/run.py`，向标准输入传入一个 UTF-8 JSON 对象。必填字段 `expression` 为字符串，去掉首尾空白后长度为 1–160。表达式使用十进制数字、括号、`+`、`-`、`*`、`/`，允许一元正负号及空格。运算采用 28 位有效数字，按四舍六入五成双舍入。脚本限制连续嵌套的运算层数。

例如，输入 `{"expression":"(0.1 + 0.2) * 10"}`，标准输出返回 `{"expression":"(0.1 + 0.2) * 10","result":"3"}`。`result` 是十进制字符串。脚本失败时，以非零状态退出并在标准错误返回原因。缺少表达式时，请用户填写；执行失败时，按脚本返回的原因处理。
